# Cooling reference pack: Motivair ChilledDoor, Motivair/Schneider CDUs, Uniflair chillers and InRow/CRAH

Retrieved 2026-09-30. Public web sources only. Media in `media/` (38 MB), provenance in `SOURCES.csv`.
Scope: the liquid-cooling plant for the mixed H200 (air-cooled, rear-door) + GB300 NVL72 (DLC) hall. Facility §4 of `../facility/README.md` had a ChilledDoor row with dimensions NOT FOUND; §1 below resolves what can be resolved (depth, fans, power, swing, models) and records what cannot (door weight, pressure drop, capacity-vs-water-temperature curve). Loop temperatures / Schneider RD numbers are deliberately NOT covered here (another pack). Figures marked "derived" are my arithmetic on cited numbers; "est" = my reading of a photo.
